MyLibrary Theme Maker

图片、字体和主题包仅在当前浏览器中处理，不会上传。

一、基础信息

填写 Manifest v1 的主题身份信息。

二、三种表面

BACKGROUND、CARD 和 DIALOG 各自选择纯色或图片。

三、五种内容颜色

色板、ARGB 与 Alpha 会同步；制作器不会自动改写配色。

文字与背景对比度可能较低

四、字体

仅支持 TTF。B 未提供时回退 A，A 也未提供时使用系统字体。

字体角色映射

最终兼容性仍由 MyLibrary Android App 导入校验决定。

五、导航图标

每个槽位可单独配置；未选择 normal 时使用 App 内置图标。

六、系统栏

系统栏图标明暗由主题显式指定，不根据背景自动推断。
